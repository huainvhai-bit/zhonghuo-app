## 📚 重要教训

1. **推送后必须验证服务器已拉取**
   - 本地推送 ≠ 服务器已更新
   - 必须在服务器上执行 `git pull`
   - 使用 `git log --oneline -3` 验证版本

2. **诊断页面很有用**
   - `api/diagnose-all.php` 可以检查所有问题
   - PHP 扩展、数据库连接、表状态、数据量
   - 应该作为部署后的第一个检查点

3. **日志是关键**
   - 前端控制台日志显示同步是否触发
   - 后端日志显示 API 是否被调用
   - 数据库查询显示数据是否写入
