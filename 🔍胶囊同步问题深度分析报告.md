### 修复 2：增强 parseGraphQLInlineArgs 鲁棒性

如果必须使用内联传参，修复解析逻辑：

```php
function parseGraphQLInlineArgs($query, $funcName) {
    $args = [];
    
    // 匹配函数调用
    $pattern = '/' . preg_quote($funcName, '/') . '\s*\((.*?)\)\s*\{/s';
    if (!preg_match($pattern, $query, $matches)) {
        error_log("parseGraphQLInlineArgs: Pattern match FAILED");
        return $args;
    }
    
    $argsStr = $matches[1] ?? '';
    error_log("parseGraphQLInlineArgs argsStr: " . substr($argsStr, 0, 200));
    
    // 解析 capsules 数组
    if (preg_match('/capsules\s*:\s*\[(.*?)\]/s', $argsStr, $arrMatch)) {
        $capsulesStr = $arrMatch[1];
        $capsules = [];
        
        // 使用更简单的正则匹配对象
        // 匹配 { ... } 内容，支持嵌套
        $depth = 0;
        $start = -1;
        $objects = [];
        
        for ($i = 0; $i < strlen($capsulesStr); $i++) {
            if ($capsulesStr[$i] === '{') {
                if ($depth === 0) $start = $i;
                $depth++;
            } elseif ($capsulesStr[$i] === '}') {
                $depth--;
                if ($depth === 0 && $start >= 0) {
                    $objects[] = substr($capsulesStr, $start + 1, $i - $start - 1);
                    $start = -1;
                }
            }
        }
        
        // 解析每个对象
        foreach ($objects as $objStr) {
            $capsule = [];
            
            // 匹配键值对：key: "value" 或 key: value
            if (preg_match_all('/(\w+)\s*:\s*("(?:[^"\\\\]|\\\\.)*"|\d+|true|false|null)/', $objStr, $fieldMatches)) {
                foreach ($fieldMatches[1] as $j => $field) {
                    $val = trim($fieldMatches[2][$j]);
                    
                    // 去除引号
                    if (strpos($val, '"') === 0 && strrpos($val, '"') === strlen($val) - 1) {
                        $val = substr($val, 1, -1);
                        $val = str_replace('\\"', '"', $val);
                        $val = stripslashes($val);
                    } elseif ($val === 'true') {
                        $val = true;
                    } elseif ($val === 'false') {
                        $val = false;
                    } elseif ($val === 'null') {
                        $val = null;
                    } elseif (is_numeric($val)) {
                        $val = strpos($val, '.') !== false ? floatval($val) : intval($val);
                    }
                    
                    $capsule[$field] = $val;
                }
            }
            
            if (!empty($capsule)) {
                $capsules[] = $capsule;
            }
        }
        
        error_log("parseGraphQLInlineArgs: Parsed " . count($capsules) . " capsules");
        
        if (!empty($capsules)) {
            $args['capsules'] = $capsules;
        }
    }
    
    return $args;
}
```
